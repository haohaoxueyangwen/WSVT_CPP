# BB11 GPU 工程优化复测，2026-10-11

原版 0.1.0 保留不变；独立优化版为 0.1.1。亚像素拟合、候选搜索、样条、相位积分、搜索半窗和精度规则没有改动。

## 实测结果

|任务/版本|求解器（ms）|API 返回（ms）|常驻缓冲区（GiB）|
|---|---:|---:|---:|
|WXST / 旧版|46.82 ± 1.01|66.67 ± 1.14|1.595|
|WXST / 减少结果拷贝|46.48 ± 0.89|57.04 ± 0.89|1.595|
|WXST / 减少结果拷贝＋中间栈|46.18 ± 1.26|56.90 ± 1.28|1.595|
|WSVT / 旧版|198.80 ± 3.98|216.22 ± 4.13|6.477|
|WSVT / 减少结果拷贝|198.65 ± 3.03|207.01 ± 3.06|6.477|
|WSVT / 减少结果拷贝＋中间栈|207.85 ± 4.15|216.18 ± 4.22|4.257|

WXST API 返回平均耗时下降 14.6%；WSVT 只减少结果拷贝的速度配置下降 4.3%。WSVT 低内存配置的常驻 GPU 缓冲区减少 34.3%（约2.22 GiB），求解器耗时增加 4.6%，完整 API 返回时间基本持平。因此低内存模式适合资源受限场景，不作为本机更快求解器的证据。

返回阶段（七字段下载＋包装）的耗时约17.3ms→8.2ms。保留了独立的主机 Tensor，由 NumPy.base 维持生命周期；去掉的是随后多余的 NumPy 内存复制，GPU→CPU 下载仍然存在。没有复用会被下一次 solve 覆盖的主机缓冲区。

## 改动与取舍

- WSVT 移除100×2048×2048的归一化float32栈，省1.5625GiB；在细层小波加载和粗层空间横向滤波加载时完成相同的double归一化并舍入float32。保持“归一化→空间x→空间y→时间小波”的粗层顺序。
- 粗层横向滤波使用共享内存行块，并将100通道的临时缓冲区缩到16通道，复用后继续原有纵向滤波。完整粗层栈仍保留，未声称消除所有中间数据。
- 节省栈需要在细层和粗层分别归一化；实测样品前端约24.5ms→28.9ms。这解释了低内存配置的阶段取舍，不归因于未经测量的带宽饱和。
- bounded探索只比较chunk16/32/100各3次，16的探索均值最低且缓冲区最小；差距较小，不声称全局最优。原记录见full_wsvt/chunk_trials.json。
- `configs/wsvt_speed.json`：materialized工作区＋减少输出拷贝；`configs/wsvt_memory.json`：streamed工作区＋chunk16＋减少拷贝（默认）。两者算法与输出相同。

## 计时规则与证据

服务器ps，单路EPYC9J14，单张RTX5880Ada GPU0；CUDA12.8.93，GCC12.3，SM89，--fmad=false；Torch2.1.2+cu118。原始BB11 TIFF uint16输入经逐文件SHA核对；WXST转换float32，WSVT保留uint16。半窗10、粗5、细4、两层、I1、cut1、WXST7×7模板、WSVT100帧无空间模板、暗场关闭、GPU样条、主机2线程；几何设置沿用上一轮控制值，非新校准。

每组1次预热、5次正式测量，原版/拷贝优化/栈优化交替顺序；参考每次完整准备，不使用静态参考缓存加速。开始/每次运行检查无其他CUDA进程和CPU负载适合计时；负载状态随逐次记录保存。硬件时钟未锁定，不解释细微求解器差异为确定提升。

Solver计时包含参考准备、样品求解、输入上传和最终同步，排除结果下载与磁盘读写；API计时从就绪主机数组到七个独立NumPy输出，包含验证、参考准备、下载，排除初始化与磁盘I/O。均值±样本标准差。显存列为持久缓冲区总字节，非CUDA分配器/进程峰值；交替计时时多个会话同时驻留。

第一轮full_*在最后一次测量中保留多个输出，出现返回时间波动，未删任何点。修正测试方法，在正式计时前保存/比较输出，所有正式轮次均立即释放返回数组；controlled_*为该预先说明的复测，表中使用整组5次数据。两个批次和所有探索数据均保留。

本机CPU对照沿用此前完整独立CLI基准，未在这轮重复测量，也不将旧CPU或Orin时间混入新旧GPU比较。新优化尚未在Orin实测。
