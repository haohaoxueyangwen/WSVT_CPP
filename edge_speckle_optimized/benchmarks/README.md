# 计时与实验边界

本次整理只进行短时功能回归，不重跑全尺寸性能实验。已有计时批次按 `docs/evidence_registry.json` 查找，不混合不同日期、输入、硬件与参考策略。

当前CLI支持独立模式的 bounded重复测量：`--warmup 1 --repeats 5 --reference-policy each-pair`。默认先报告求解器和API两个时间。静态参考复用是另一使用场景，首次准备单列。WXST与WSVT分别统计，不合成一个“XST/SVT总耗时”。

复测须固定：输入哈希、图像尺寸/帧数、总半窗10、粗5/细4、模板、小波与迭代参数、完整输出、几何值、线程数、GPU/CPU、工具链、功耗/时钟状态、预热和重复次数。CPU、GPU候选轮换顺序执行，不能用同时存活多个会话的测量推断单个版本峰值内存。

细层WXST融合把模板生成、小波和SSD放进匹配kernel，匹配事件包含这些工作。常驻缓冲字节不是进程峰值内存。CPU `displace_including_features_s` 包含前端，不是纯SSD搜索时间。

旧GPU原型与edge的比较、原C++CPU与edge的同机比较属于两个实验组。原C++与新CUDA存在少量局部差异；按原有记录报告，不用当前整理前后相同结果替代跨后端质量证据。
