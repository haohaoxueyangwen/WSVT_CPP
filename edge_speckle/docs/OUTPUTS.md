# 输出与计时契约（schema_version=1）

| 字段 | 单位 | 形状 | 原图左上角坐标(y,x) |
|---|---|---|---|
| `displace_y`, `displace_x` | 探测器pixel | (H−20)×(W−20) | (10,10) |
| `DPC_y`, `DPC_x` | rad，波前偏折角 | (H−20)×(W−20) | (10,10) |
| `phase` | rad，相对相位、零均值 | (H−20)×(W−20) | (10,10) |
| `transmission` | 无量纲 | H×W | (0,0) |
| `match_score_neg_ssd` | 负SSD，任意单位 | (H−20)×(W−20) | (10,10) |

七字段均为float32。x为列、y为行；位移采用原实现符号约定，DPC由去均值位移乘像素尺寸/传播距离得到，相位保持原FFT积分符号。默认不生成物理暗场。负SSD是匹配代价，不是透射率或暗场。

透射率继续沿用本候选的首帧强度比和截断规则，WSVT输出并非100帧平均透射率；不要只凭字段名推断物理定义。

裁取同一原图区域时，必须按各字段的原点换算。例如原图 `y=400:900, x=200:800` 对应位移/相位 `y=390:890, x=190:790`，透射率仍取原始索引。不自动改动历史裁块。

`report.json` 保存解析后的参数、输入哈希、几何来源、设备、原生构建记录、各次计时、输出形状与坐标。`status.json` 区分运行、完成、失败；结果目录拒绝覆盖。

| 时间项 | 包含 | 不包含 |
|---|---|---|
| `sample_solver_s` | 样品输入写入、前端/匹配、样条、DPC/相位及同步 | 参考准备、验证、输出下载、文件I/O |
| `reference_prepare_this_call_s` | 参考写入与特征准备，当前实现的函数时间 | 文件I/O |
| `solver_this_call_s` | 上两项相加；静态参考时只计样品 | 初始化、下载、文件I/O |
| `api_this_call_s` | 参考/样品检查、准备、求解、独立输出下载 | 初始化、文件I/O |
| `file_read_and_conversion_s` | NPZ读取及入口检查/类型整理 | 求解 |
| `file_save_s` | 压缩NPZ保存 | 求解 |
| `run_wall_before_report_s` | 本命令读入、哈希、初始化、预热、全部测量与保存 | 最后报告写入 |

当前底层 `reference_prepare_s` 的计时在输入验证之后开始；`solver_this_call_s` 因而包含参考的缓冲写入/计算与部分调用管理成本。参考项是墙钟时间，不是纯CUDA事件时间。样品阶段 `gpu_event_s` 用来定位阶段；不能直接把其总和当成API延迟。CPU样条事件还会跨越主机处理与等待。

整体命令时间包含预热和多次求解，不称为单对端到端延迟。`reference-policy static` 的首次准备单列，不能与 `each-pair` 混算加速比。输出下载与保存分别计时，文件压缩策略须与被比较版本一起记录。
