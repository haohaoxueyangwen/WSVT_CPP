# 工程包简要约定

WSVT为多扫描帧时间向量；WXST为单对图像的空间模板，前端独立。默认半窗10、粗5、细4、两层、一次迭代、小波截断1；WXST7×7/58维，WSVT100帧/63维且无空间模板。

CPU基线标签FASTWSVT-cpp / FASTWXST-cpp；新Jetson实现称edge GPU，避免覆盖论文中的既有GPU或CPU含义。OpenMP是CPU运行库，SIMD来自原CPU编译器路径，CUDA由原生kernel实现。

共享DRAM不等于没有内存搬移、同步或缓存成本。当前设备缓冲复用、WXST样品融合、WSVT16位输入以及计划样条为默认工程路线。重排是显式实验；不将其推广到WXST。

输出为七字段float32，负SSD不是物理暗场，WSVT透射率仍按候选首帧比计算。公开几何值必须明确提供。质量接受、跨后端数值门限、性能与工程回归分别记录。

本轮只创建独立目录和文件；保护原仓库、论文与实测记录，来源转换有哈希清单。
